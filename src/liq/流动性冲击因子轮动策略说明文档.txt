流动性冲击因子轮动策略说明文档

策略概述
本策略基于流动性冲击敏感度差异构建指数轮动模型，通过量化分析中证500指数与红利低波指数（HL）对成交量的敏感程度差异，动态调整资产配置。
核心逻辑：当某指数单位成交量引发的价格波动更大时（流动性冲击更显著），预示其短期定价效率较低，策略将降低该指数权重。

策略逻辑详解
信号构建（无未来函数设计）
====================================================
# 流动性冲击指标 = 窗口平均收益率 / 窗口平均成交额
Signal_500 = mean(Ret_500, 40) / mean(TV_500, 40)
Signal_HL  = mean(Ret_HL, 40)  / mean(TV_HL, 40)

# 相对信号（消除市场共性波动）
Signal = Signal_500 - Signal_HL

# 历史分位数标准化（20日窗口）
Signal_Rank = percentileofscore(Signal过去20日, 当前Signal)
====================================================

仓位管理（Sigmoid平滑调仓）
====================================================
# 将分位数映射为仓位（中心点0.5 → 50%:50%）
Target_500 = sigmoid(Signal_Rank - 0.5, scale=8)  # [0,1]连续仓位
Target_HL  = 1 - Target_500

# 实际持仓 = 前一日目标仓位（T-1信号决定T日仓位）
Position_500 = Target_500.shift(1).fillna(0.5)
====================================================
